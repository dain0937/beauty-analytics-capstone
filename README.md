# Makeup Product & Review Analytics — Capstone Project

This project explores the makeup market using product data and customer reviews to understand:
- What product attributes drive customer satisfaction
- Natural product/customer segments via clustering
- How text sentiment aligns with reviews using BERT

## 🚀 Highlights
- Cleaned & engineered product + review datasets
- Identified natural product clusters (K-Means, Hierarchical, K-Medoids)
- Text-based sentiment using BERT to supplement review rating bias
- Visual insights into pricing tiers, engagement skew, and product success signals
